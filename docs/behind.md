# 作品幕后（L49 · 1.49.0）

摄影栏目新增 **作品幕后** `/behind/`：一张照片是怎么拍出来的——拍摄参数、俯视布光示意、步骤、器材和相关术语。

- **页面**：`/behind/` 按日期倒序列出幕后记录（参数文字、光源数）；`/behind/:slug/` 预渲染为：作品照片、拍摄参数（`dl`：相机、镜头、焦距、光圈、快门、ISO）、**布光示意 SVG**（俯视，`role="img"` + `<title>` + `<desc>`，`figcaption` 是同一段文字描述——示意图的文字替代是必填项）、光源列表（类型、说明、功率、相对相机的角度与光位名称，例如「左 96° · 侧光」「180° · 逆光」）、拍摄步骤、器材（链接到 `/gear/`）、相关术语（链接到 `/glossary/:slug/`）。没有 JS 也完整。
- **共享核心**：`behind-core.ts`（web 与 worker 逐字相同）：`lightAngle`（主体→相机与主体→光源两个向量的有向夹角，左正右负，正后方 180°）、`positionName`（正面光 / 前侧光 / 侧光 / 侧逆光 / 逆光）、`angleText`、`exifText`；校验：照片替代文字、焦距 4–1200mm、光圈 f/0.95–64、快门 `1/125` 或 `8s`、ISO 25–204800、相机 / 主体 / 光源坐标 0–100、光源 1–6 个且编号唯一、布光文字描述 10–600 字、步骤 1–10 条、器材 ≤ 8、术语 ≤ 8 且地址合法不重复。
- **接口**：`GET /api/behind`、`GET /api/behind/:slug`（只给已发布）；站长 `GET /api/admin/behind`、`GET / PUT / DELETE /api/admin/behind/:slug`。D1 表 `behind_scenes`（迁移 `0040_behind.sql`）；正式库迁移 SKIPPED-verifiable。
- **演示数据**：2 份已发布 + 1 份草稿；过程、器材和布光为虚构示例，照片是站内开放授权示例照片（参数不是原图 EXIF）；示例术语都能在术语表里找到（单元测试检查）。
