# 课程笔记（L40 · 1.40.0）

专题栏目新增 **课程笔记** `/courses/`：摄影专业课的课堂笔记、作业要求和评分量表，按学期整理。

- **页面**：`/courses/` 按学期倒序列出课程（课时数、作业数、完成度）；`/courses/:slug/` 预渲染为课时列表，每节课有笔记要点，带作业的课时显示截止日期、要求和评分量表表格（评分项 / 权重 / 得分）以及加权总分和等级。没有 JS 也完整。
- **共享核心**：`course-core.ts`（web 与 worker 逐字相同）：地址规则同其他栏目；课时最多 24 节；评分项 1–8 个，权重为 1–100 的整数且合计必须为 100，得分为 0–5 的整数（可留空）。
- **计算**：`rubricScore` = Σ 权重 × 得分 / 5，满分 100、保留一位小数；只要有一项未评分就显示「未评分」。`gradeOf`：≥90 优秀、≥80 良好、≥70 中等、≥60 及格、其余不及格。完成度 = 已写笔记的课时数 / 课时总数。
- **接口**：`GET /api/courses`、`GET /api/courses/:slug`（只给已发布）；站长 `GET /api/admin/courses`、`GET / PUT / DELETE /api/admin/courses/:slug`。D1 表 `courses`（迁移 `0031_courses.sql`）；正式库迁移 SKIPPED-verifiable。
- **演示数据**：2 门已发布课程 + 1 门草稿，课程、作业与分数均为虚构。
