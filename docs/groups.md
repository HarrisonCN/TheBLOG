# 兴趣社群：小组（L28 · 1.28.0）

## 页面（社区 › 小组）

- `/groups/`：全部小组（按成员数与最近动态排序），登录后可以 **建组**（网址 2–32 位小写字母 / 数字 / 连字符，名称 ≤ 30 字，简介 ≤ 300 字，选择「直接加入」或「需要审核」）。
- `/groups/:slug/`：小组主页——名称、简介、置顶 **公告**、成员数、我的身份，**小组动态**（成员分享进来的作品），成员列表。
- 两个页面都在构建时预渲染外壳并写进 sitemap，数据由浏览器按需加载（`groups-client.ts` 懒加载）。

## 角色与权限

| 操作 | 组长 owner | 管理员 mod | 成员 member | 申请中 / 未加入 |
|---|---|---|---|---|
| 看小组、动态 | ✓ | ✓ | ✓ | ✓（公开） |
| 分享自己的作品、删自己的分享 | ✓ | ✓ | ✓ | — |
| 审核入组申请、改置顶公告、移出成员、移除任意分享 | ✓ | ✓（只能移出比自己低的人） | — | — |
| 编辑名称 / 简介 / 加入方式、任免管理员、解散 | ✓ | — | — | — |
| 退出 | — （组长不能退出，只能解散） | ✓ | ✓ | 撤回申请 |

- 共享规则在 `web/src/group-core.ts`，Worker 用逐字相同的 `worker/src/group-core.ts`（测试比较两份文件）。
- 小组动态只能分享 **自己已发布的公开作品**；同一作品在同一小组只能分享一次。作品被删除或被管理员下架后自动从动态里消失。
- 举报沿用已有的作品举报 → 已有审核队列，没有新的举报类型。
- 尊重屏蔽：被组长或任何管理员屏蔽的人不能加入（也不能申请）；屏蔽了组长的人也不能加入。
- 频率限制：每人最多拥有 5 个小组；每天最多建 3 个；每小时最多加入 20 次、分享 10 次。

## API（`/api/social/groups`）

`GET` 列表 · `POST` 建组 · `GET / PATCH / DELETE :slug` · `POST / DELETE :slug/join` · `GET :slug/members` ·
`POST :slug/members/:username`（`{ action: approve | reject | kick | role }`）· `GET / POST :slug/feed` · `DELETE :slug/feed/:workId`。
演示站用 `web/src/demo/mock-groups.ts`（虚构的示例小组与示例账号，不代表任何真实的人）。

## 数据与迁移

- **真实部署需要执行新迁移 `0021_groups.sql`**（只做加法：`groups`、`group_members`、`group_works` 三张表，不级联；备份 / 执行 / 完整性检查 / 回滚命令写在迁移文件开头）。
  本仓库没有 Cloudflare 凭据：正式库执行 = **SKIPPED-verifiable**，测试里由 miniflare 执行。
- 注销账号：本人是组长的小组解散、成员关系与分享一并删除（`purgeGroups`，在 `purgeMember` 的同一个 batch 里）；「我的数据」导出包含小组与分享。
