# 视频与声音作品（L34 · 1.34.0）

摄影栏目下的 **视频与声音**（`/av/`）收纳短片和声音作品。

## 读者看到的

- `/av/`：按「视频」「声音」分组的卡片，显示时长、章节数和日期。
- `/av/:slug/`：浏览器原生 `<video>` / `<audio>`（`controls`、`preload="metadata"`，**不自动播放**），下面是章节和完整文字稿。
  - 章节和每一句文字稿前面的时间码都是 `?t=秒` 链接：有 JS 时点一下就跳到那里，并把 `?t=` 写进地址栏方便分享；没有 JS 也能读全文。
  - 深链参数 `?t=` 支持 `90`、`12.5`、`1:30`、`01:02:03`、`1h2m3s`、`45s`；超过时长时取时长，非法值忽略。
  - 播放时当前这句和当前章节高亮（`aria-current`）；文字稿可以搜索（忽略大小写与空白，结果数量用 `aria-live` 播报）。
  - 视频的中文字幕轨道（`<track kind="captions">`）由页面上的文字稿在浏览器里生成，和文字稿永远一致。

## 发布规则（`media-core.validateAvWork`，前端与 Worker 是同一份文件）

- 视频必须有字幕和带替代文字的封面；声音必须有文字稿。无障碍是发布条件。
- 来源 1–4 个，MIME 按类型白名单（视频：webm / mp4；声音：mpeg / ogg / webm / mp4 / aac），地址只允许 `https://` 或站内绝对路径。
- 字幕按开始时间排序、结束晚于开始、不超出时长，最多 2000 条；章节从 0 秒开始严格递增、在时长之内，最多 100 个。

## 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/av` | 已发布作品摘要（日期倒序，不含来源和字幕） |
| GET | `/api/av/:slug` | 已发布作品全文 |
| GET | `/api/av/:slug/captions.vtt` | WebVTT（`text/vtt`） |
| GET | `/api/admin/av` | 站长：含草稿 |
| GET / PUT / DELETE | `/api/admin/av/:slug` | 站长：整份写入（校验 + 地址一致）/ 删除 |

存储：D1 表 `av_works`（迁移 `0025_media.sql`）。

## 演示站与限制

- 演示站的两段示例（「示例短片：暮色色带」「示例声音：合成海浪」）是用 ffmpeg 合成的渐变画面和棕噪声，不是任何真实拍摄或录音。
- 媒体文件上传到 R2、站长后台的编辑界面：推迟。正式 Cloudflare 环境上的迁移：SKIPPED-verifiable（Worker 未部署）。
