# 摄影工具箱（L29 · 1.29.0）

栏目：**工具**（`web/src/site-map.ts` › tools）。四个页面全部是纯前端计算，没有后端接口、没有数据库迁移、没有任何网络请求。

| 页面 | 路由名 | 做什么 |
|---|---|---|
| `/tools/exposure/` | `exposure` | 曝光值 EV100 = log₂(N²/t) − log₂(ISO/100)；常见场景对照；等效组合表（保持 ISO / 光圈 / 快门三种锁定，吸附到 1/3 档，超出刻度的标「超出」而不是编一个档位）；ND 减光镜换算。支持网址参数 `?f=2.8&t=1%2F250&iso=400`（非法值回落到 f/8 · 1/125 · ISO 100）。 |
| `/tools/dof/` | `dof` | 近点 / 远点 / 景深 / 超焦距：H = f²/(N·c) + f。传感器表含全画幅、APS-C、M4/3、中画幅和四种手机传感器（1″、1/1.3″、1/1.56″、1/2.55″）；可以按 35mm 等效焦距输入（手机常见），自动换算实际焦距；弥散圆默认 = 对角线 / 1500，可手动改。 |
| `/tools/golden-hour/` | `goldenhour` | NOAA 太阳位置公式离线计算日出 / 日落（−0.833°）、正午与太阳高度、黄金时刻（−4° → +6°）、蓝调时刻（−6° → −4°），极昼 / 极夜如实提示；一天 96 格光线条；按城市当地时区显示。 |
| `/tools/exif/` | `exifviewer` | 本地 EXIF 查看器：用 `exif.ts` 在浏览器里读取机身、镜头、焦距（含等效）、光圈、快门、ISO、曝光值、裁切系数、方向；带 GPS 的照片只显示提示，**坐标从不显示、从不上传**；可下载一份去除元数据的副本（无损，不重新压缩）；可一键带参数打开曝光计算器。 |

作品集灯箱多了一行「曝光值」，由作品的光圈 / 快门 / ISO 算出，点开即在曝光计算器里带入同一组参数。

## 权限与隐私边界
- 黄金时刻默认用内置城市坐标（两位小数），**不请求定位权限**；只有点「使用我的位置」才调用 `navigator.geolocation`，结果立刻粗化到 0.1°（约 10 km，与照片地图同一精度），只在本机计算。
- EXIF 查看器用 `File.arrayBuffer()` 在本机读取；E2E 断言选图、读取、下载副本全过程零网络请求。
- 工具代码（`photo-tools-client`）按需加载：首页和 `/tools/` 落地页不下载。

## 测试
- 单元：`web/test/phototools.test.ts`（表驱动）。参考值：阳光 16 法则（EV≈15）；DOFMaster（50mm f/8 10 m c=0.03 → H 10.47 m、近 5.11 m、远 223 m）；太阳时刻对照 api.sunrise-sunset.org（北京夏至、悉尼春分）和 timeanddate.com（伦敦冬至；sunrise-sunset.org 在高纬度冬季偏差约 2 分钟），容差 2 分钟；极昼 / 极夜（朗伊尔城）。
- E2E：`blogdemo/l29.mjs`（1280 浅色 + 390 深色，axe 0）。
