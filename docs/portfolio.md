# 毕业作品集（L50 · 1.50.0 · 里程碑）

摄影栏目新增 **毕业作品集** `/portfolio/`：按策展顺序排好的作品序列 + 创作自述，打印时一页一件。它也是 **1.50 里程碑** 的总入口：列表页汇总了 1.36–1.49 每个版本新增的内容栏目。

- **页面**：`/portfolio/` 显示里程碑说明（`role="note"`）、作品集卡片（作者、年份、件数）和「1.36–1.49 新增的内容栏目」14 个入口（术语表、修图前后、拍摄清单、照片日历、课程笔记、作品点评、扫街路线、色彩研究、摄影人访谈、52 周挑战、胶片记录、构图辅助线、投稿与展览征集、作品幕后）。`/portfolio/:slug/` 预渲染为：虚构声明、作者与年份、创作自述、策展序列（有序列表；每件一个 `figure`，说明行「n / N · 作品名 · 年份 · 媒介 · 尺寸」+ 可选说明）。没有 JS 也完整。
- **打印**：打印样式让每件作品从新的一页开始（`break-before: page`），隐藏导航与按钮；JS 加载后出现「打印作品集（一页一件）」按钮，调用浏览器打印。
- **共享核心**：`portfolio-core.ts`（web 与 worker 逐字相同）：`seqText`、`workLine`、`HUB`（14 个入口，单元测试检查版本连续、地址唯一且都是已注册的路由）；校验：`fictional: true`、年份 1990–2100、自述 1–6 段、策展序列 3–24 件且序号从 1 起连续、每件照片替代文字与宽高、媒介必填。
- **接口**：`GET /api/portfolio`、`GET /api/portfolio/:slug`（只给已发布）；站长 `GET /api/admin/portfolio`、`GET / PUT / DELETE /api/admin/portfolio/:slug`。D1 表 `portfolios`（迁移 `0041_portfolio.sql`）；正式库迁移 SKIPPED-verifiable。
- **演示数据**：2 份已发布（6 件、3 件）+ 1 份草稿；作者与自述虚构，照片是站内开放授权示例图。
