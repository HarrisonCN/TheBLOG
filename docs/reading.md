# 阅读与书影音 2.0（L27 · 1.27.0）

## 书摘 `/quotes/`（专题 › 书摘）

- 来源两处：文章正文里的 `:::quote 来源 | 链接` 块，以及书影音条目的「摘录一句」字段（后台书影音表单，≤ 200 字）。
- 按来源筛选（全部 / 来自文章 / 来自书影音），每张卡片都能用已有的引用卡片生成分享图片。
- 来自文章的卡片链回那一段：`/posts/:slug/#q-xxxxxxx`。锚点只由摘录正文（去掉 Markdown 记号、空白归一）的 FNV-1a 哈希决定，
  所以重新渲染、在前后增删内容、改文章标题都不会让链接失效；代码块里的 `:::quote` 不算书摘。
- 数据：`GET /api/quotes`（Worker 与演示 mock 同一份 `reading-core.ts`，只取已发布文章，最多 200 段）；书影音摘录来自 `/api/content/shelf`。

## 年度书影音 `/shelf/:year/`

- 书影音页顶部出现「年度回顾」年份入口（只列出有标记时间的年份）。
- 每年一页：总数、已完成 / 进行中 / 想看、平均分（只算评过分的）、12 个月分布、4 星以上推荐、全部条目，上一年 / 下一年切换。
- 构建时逐年预渲染并写进 sitemap；没有条目的年份返回「页面不存在」。

## 稍后读 `/reading-list/`（工具 › 稍后读）

- 文章页工具栏的「稍后读」开关把文章加入清单；清单 **只保存在这台设备的浏览器里**（`localStorage` 的 `blog-later`，最多 100 条），不上传任何数据。
- 清单合并本机阅读进度（读到 ≥ 95% 算读完，读完的排在后面），可以移除，可以复制或下载为 Markdown（`reading-list.md`）。
- 这个页面不进搜索引擎索引（`noindex`），也不在 sitemap 里。

## 没有做 / 推迟

- 会员的书摘与稍后读跨设备同步（D1）：**SKIPPED-verifiable**，访客与演示站都只用本机存储。
- 后台「Open Library 元数据刷新」（P2）：本版没有做。
