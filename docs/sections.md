# 栏目地图（L23 · 1.23.0「栏目整理」）

全站的信息架构只有一个来源：`web/src/site-map.ts` 里的 `SITE_SECTIONS`。顶部导航和下拉、手机菜单、⌘K 命令面板、首页「逛逛别的栏目」、
全部栏目页 `/sections/`、新栏目的落地页、预渲染 + `sitemap.xml`，以及「我的」页的快捷入口，都从这份注册表生成。

`web/test/site-map.test.ts` 保证：

- 除 404 外，每个路由**恰好属于一个栏目**（没有孤儿路由，也没有重复归属）；`ROUTE_NAMES`（render.ts）在编译期穷举全部路由；
- 每个条目的链接都解析到它声明的路由，每个栏目的入口页属于本栏目；
- 1.22 及更早的网址全部照旧解析（这一版只加新路由，没有改动或重定向旧网址）；
- 新栏目的落地页列出每个条目（图标 + 名称 + 一句话说明）；
- 只给登录用户 / 站长看的条目默认隐藏，⌘K 按身份过滤。

## 栏目与条目

★ = 1.23.0 新开的栏目（有自己的落地页）· ⊕ = 1.23.0 新增的路由 · 👤 = 登录后可见 · 🔑 = 站长登录后台后可见

| 文章 | `/archives/` | 归档（含文章页）· 系列连载 ⊕ `/series/` · 搜索 · 数据 · 订阅（RSS / Atom / JSON Feed、邮件摘要） |
| 专题 | `/categories/` | 分类专题 · 标签 · 书影音 · 收藏与项目 |

和 1.22 相比搬了家的条目：发现 / 社区动态 / 摄影活动 / 留言与便签（原来在「关于」）→ 社区；登录与徽章（原来在「关于」）→ 账号。
原来只能从别处点进去的功能现在都有栏目：系列连载、影集（之前没有列表页）、话题、发布作品、运行状态、私信与设置、我的数据、
隐私与安全中心、音乐播放器、阅读设置、命令面板。

## 身份与可见性

- 注册表里 `audience: 'member' | 'admin'` 的条目在 HTML 里输出 `data-aud` + `hidden`，预渲染页面默认不露出；
  浏览器端 `web/src/audience.ts` 在每次换页和登录状态变化（`blog:member` 事件）时按身份切换。
- 站长身份：只有在本浏览器登录过后台（admin.ts 在 localStorage 写 `blog-admin-hint`，退出时清除）才会向 `/api/auth/session` 确认一次，
  普通访客不多发请求。这只决定入口显不显示，**权限仍然全部由服务端判断**。
- 页脚的「后台」链接保留（站长从这里登录）。
- 只属于个人的页面（我的、通知、发布、我的数据、私信与设置）照旧预渲染外壳，但不进 sitemap。

## 新增功能时

1. 在合适的栏目里加一个条目：`id`、`label`、`icon`（icons.ts 里的名字）、一句话 `desc`（≤ 40 字）、`href` 或 `action`、`routes`（它负责的路由名，
   含详情页）；只给登录用户 / 站长看的加 `audience`，不进 sitemap 的加 `index: false`。
2. 没有合适的栏目时新开一个（`isNew: true`），给它一个落地页路由，并在 render.ts 的 `renderRoute` 里交给 `sectionLanding`。
3. 跑 `npm test -w web`：漏挂的路由会让 site-map.test.ts 失败。
