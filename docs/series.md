# 系列与影集 2.0（L25 · 1.25.0）

## 系列详情 `/series/:系列名/`

- 网址直接用系列名（和标签页 `/tags/:标签/` 一样，GitHub Pages 按解码后的路径找文件）。名字里带 `/`、`\` 或以 `.` 开头的系列不生成详情页。
- 页面内容：封面（第一篇有封面的文章）、简介（第一篇的摘要）、**已完结 / 连载中**、按发布时间排好的篇目、「我的阅读进度」、打印 / 存为 PDF。
- **完结**：在系列最后一篇文章加标签 `完结` 即标为已完结；之后再发新的一篇，状态自动回到连载中。
- **阅读进度只存在访客自己的浏览器里**：复用「继续阅读」的本机记录（localStorage `blog-reading`，读到 ≥ 95% 算读完）。
  进度条显示已读篇数，按钮会变成「继续读第 N 篇」（最前面一篇没读完的）或「再读一遍」。不上传任何数据。
  会员跨设备同步需要 Worker D1，**未实现（SKIPPED-verifiable）**。
- 文章页的系列导航里，系列名链接到系列详情；`/series/` 列表里每个系列的标题也链接到详情。
- 打印：系列详情页带打印样式（隐藏导航、进度和按钮，篇目不跨页断开），浏览器「打印 → 存为 PDF」即可。

## 月度合集 `/monthly/`、`/monthly/YYYY-MM/`

- 自动生成：把某个月发布的 **文章、影集** 和作品集里 **作品**（按作品的拍摄日期）放到一页，不需要手工维护。
- 月份按 **Asia/Shanghai** 切分：例如 UTC 8 月 31 日 16:30 发布的文章算 9 月。作品只有日期，按字面月份。
- 月份页有「上一月 / 下一月」（只在有内容的月份之间跳）和「全部月份」；没有内容的月份是 404。
- 预渲染为每个有内容的月份输出静态页，并写进 sitemap。

## 影集章节

- 影集照片多了一个可选字段 `chapter`（≤ 40 字）：从这张照片开始新的一章。第一章之前的照片归入「开篇」。
- 文章页在影集上方显示章节跳转（每章几张），每章第一张照片前有章节标题，锚点唯一（重名自动加 `-2`、`-3`）。
- 校验在 `web/src/essay-core.ts` 与 `worker/src/essay-core.ts`（同一份文件）；字段存在影集 JSON 里，**不需要数据库迁移**。

## 代码

- `web/src/series-core.ts`：纯函数（系列分组 / 状态 / 进度、月份分组、上一月下一月、章节锚点、影集章节），单元测试 `web/test/series.test.ts`。
- `web/src/series-view.ts`：系列详情、月度合集页面；`web/src/series-client.ts`：浏览器端填充阅读进度（按需加载）；`web/src/series.css`。
- 路由 `seriesdetail`（「文章 › 系列连载」条目）、`monthly` / `month`（「摄影 › 月度合集」新条目）登记在 `web/src/site-map.ts`。
