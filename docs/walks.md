# 扫街路线（L42 · 1.42.0）

摄影栏目新增 **扫街路线** `/walks/`：走一圈能拍到什么——站点、拍摄提示、距离和预计用时。

- **页面**：`/walks/` 按日期倒序列出路线（区域、站点数、总距离、预计用时）；`/walks/:slug/` 预渲染为站点有序列表（每站的拍摄提示和到下一站的距离）、内联 SVG 路线示意图（`role="img"`，配文字说明；不加载任何地图瓦片或第三方脚本），以及「下载 GPX」。没有 JS 也完整。
- **共享核心**：`walk-core.ts`（web 与 worker 逐字相同）：站点 2–15 个、编号唯一、经纬度在合法范围；步速 2–7 公里 / 小时（默认 4）。
- **计算**：`haversine` 球面距离（地球半径 6371 km），分段取整到米；预计用时 = 总距离 ÷ 步速 + 中间站点数 × 每站停留分钟。示意图用等距矩形投影（按平均纬度修正经度），保持比例。`toGpx` 输出 GPX 1.1 路线点（`rtept`），名称经 XML 转义。
- **接口**：`GET /api/walks`、`GET /api/walks/:slug`（只给已发布）；站长 `GET /api/admin/walks`、`GET / PUT / DELETE /api/admin/walks/:slug`。D1 表 `walks`（迁移 `0033_walks.sql`）；正式库迁移 SKIPPED-verifiable。
- **演示数据**：2 条已发布路线 + 1 条草稿，地点与提示均为虚构示例。
